# Database migration history

Drizzle Kit generated SQL migrations belong in this directory and must be committed to Git.

- Generate a migration after changing `src/db/schema`: `pnpm db:generate`.
- Review the generated SQL before running it.
- Apply pending migrations: `pnpm db:migrate`.
- Never modify a migration that has already been applied to a shared environment. Add a forward-only migration instead.

The migration journal generated by Drizzle is the authoritative ordered migration history. No production database migration has been applied by this repository commit.
